# MUTATE THE WORLD

An original multiplayer Roblox game about collecting strange creatures, mutating them with
elemental crystals, running a floating-island economy, raiding other players' islands and
defending your own.

This repository is a complete [Rojo](https://rojo.space) project: every script, the remotes,
the UI and the world generator are source files that build into a Roblox place file.

## Quick start (Roblox Studio)

You need Roblox Studio plus either the Rojo CLI or the prebuilt place file.

**Option A: open the built place (fastest)**

1. Build it (or use an existing `build/MutateTheWorld.rbxlx`):

   ```bash
   rojo build default.project.json -o build/MutateTheWorld.rbxlx
   ```

2. Double-click `build/MutateTheWorld.rbxlx` to open it in Roblox Studio.
3. Press **Play**. The world is generated by the server at startup (it is not saved in the
   place), so the Edit view looks almost empty. That is expected.

**Option B: live sync while editing**

1. Install the Rojo Studio plugin (Studio > Plugins > search "Rojo", or `rojo plugin install`).
2. Run `rojo serve default.project.json` in this folder.
3. In Studio, open a new Baseplate, delete the Baseplate part, click **Connect** in the Rojo plugin.

**Saving progress (DataStores)**

Without extra setup the game runs with session-only saving and tells the player so. To test
real saving in Studio: publish the place (File > Publish to Roblox), then
Game Settings > Security > enable **Enable Studio Access to API Services**.

**Recommended game settings**

- Game Settings > Places > Max players: **8** (one island per player; extra players are kicked politely).
- Game Settings > Avatar: R15 or R6 both work.

**Multiplayer test in Studio:** Test tab > Clients and Servers > 2 or 3 players > Start.

## Project layout

```
default.project.json     Rojo tree (also declares the RemoteEvents/RemoteFunction)
src/shared/              -> ReplicatedStorage.Shared   configs, rules, procedural creature models
src/server/              -> ServerScriptService.Server Main script, Core (pure logic), Services, World builders
src/client/              -> StarterPlayerScripts.Client Main LocalScript, UI, controllers
tests/                   pure-logic test suite + property checker (run outside Roblox)
scripts/verify.sh        runs every check
docs/                    documentation
```

## Verify

```bash
scripts/verify.sh
```

Runs the 44 logic tests with the `luau` CLI, the property checker, a Roblox API type check
(if `luau-lsp` and its definitions file are available) and `rojo build`. Details in
[docs/TESTING.md](docs/TESTING.md).
